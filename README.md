# Azure-Cloud-Portofolio

Hands-on Azure projects demonstrating cloud infrastructure,
networking, storage, identity, security, monitoring, and
cost management.

## Projects

### Project 1 — Virtual Machines and RBAC

Exploring Azure virtual machines, role-based access control,
permissions, governance, and cost management.

### Project 2 — Virtual Networks and Private Endpoints

Exploring VNets, subnets, network security groups, private
endpoints, private DNS, and secure connectivity.

### Project 3 — Storage Accounts and Access Tiers

Exploring Azure Storage, Blob Storage, access tiers,
lifecycle management, and storage security.

### Project 4 — Entra ID and Conditional Access

Exploring identity, RBAC, MFA, Conditional Access,
and identity governance.

### Project 5 — Azure Monitor and Log Analytics

Exploring Azure Monitor, Log Analytics, KQL queries,
logging, alerts, and troubleshooting.
